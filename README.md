# Flask Web Application

Простое веб‑приложение на Flask — демонстрационный проект для изучения основ веб‑разработки на Python.

## Описание проекта

Это базовое Flask‑приложение демонстрирует:

* маршрутизацию URL;
* рендеринг шаблонов HTML;
* работу со статическими файлами (CSS, изображения);
* базовую структуру Flask‑приложения.

## Технологии

* **Python** — язык программирования;
* **Flask** — микрофреймворк для веб‑приложений;
* **HTML5** — разметка веб‑страниц;
* **CSS3** — стилизация интерфейса;
* **Git** — контроль версий;
* **GitHub** — хостинг кода.

### Предварительные требования

* Установленный **Python 3.8+**;
* установленный **pip** (менеджер пакетов Python);
* установленный **Git** (опционально, для клонирования).
